# WorkTrail

A lightweight Korean work log for overtime and business trips.

## Public website

https://yayanaya1007.github.io/WorkTrail/

## Features

- Record overtime start and end times, or trip departure and return times.
- See actual elapsed time and recognized time separately.
- Include lunch time in the elapsed time.
- Cap recognized time at four hours per record for both overtime and trips.
- Review monthly totals and export CSV or back up and restore records as JSON.

## Run

Open `dist/index.html` in a modern browser, or host the `dist` directory as a static site.

Records are stored in the browser's local storage. They are not synced across browsers or devices.
